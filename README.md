Автор: Кірілл Ярмолінський.

| Файл | Теорема |

## Звіти

Звіти лежать у папці `reports/`: доведення, контрприклади, опис візуалізації та використання ШІ.

## Технічно

Чистий HTML + JavaScript (Canvas), без збірки і без залежностей, крім шрифтів Google Fonts. Щоб запустити локально, достатньо відкрити будь-який `.html` у браузері. Усі обчислення виконуються в браузері.
